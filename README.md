# Food-Production-Analysis
A data analytics project focused on exploring global food production trends using Power BI. It includes data collection, preprocessing, visualization, and an interactive dashboard to highlight key insights for informed agricultural decision-making.

# 🌾 Food Production Analysis

This project analyzes global food production trends using **Power BI**. It focuses on crop-wise and country-wise production to uncover insights, visualize key patterns, and support better agricultural planning and policy-making.

---

## 📌 Project Objectives
- Analyze global food production data by crop and country.
- Identify top producers and underperforming regions.
- Develop an interactive Power BI dashboard to present insights visually.
